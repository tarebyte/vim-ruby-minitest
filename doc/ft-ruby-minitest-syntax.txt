RUBY MINITEST             *ruby-minitest-syntax.vim*  *ft-rubyminitest-syntax*

==============================================================================
REQUIREMENTS ~

  - Neovim 0.9 or later.
  - The `ruby` |treesitter| parser, e.g. via `:TSInstall ruby`.
  - Treesitter highlighting active for Ruby buffers, e.g. by calling
    `vim.treesitter.start()` from a FileType autocommand, or by using a
    distribution that does so for you.

This plug-in ships a single query file, `after/queries/ruby/highlights.scm`,
which `; extends` the stock Ruby highlights query.  Nothing is highlighted if
treesitter highlighting is off; there is no regex-syntax fallback.

==============================================================================
HIGHLIGHT GROUPS ~

Two capture groups are used:

  `@function.builtin`   Assertions and expectations: `assert_equal`, `refute_nil`,
                      `must_equal`, `wont_include`, `skip`, `flunk`, `pass`, and
                      the `_()` / `value()` / `expect()` wrappers.

  `@function.macro`     Spec DSL blocks: `describe`, `it`, `specify`, `before`,
                      `after`, `setup`, `teardown`, `context`, `let`, `subject`,
                      `feature`, `scenario`, `background`.

The DSL group only matches when the call takes a block, so ordinary Ruby code
that happens to call a method named `context` or `feature` is left alone.

Note: Neovim core does not link `@function.macro` to anything by default.  Most
colorschemes define it; if yours does not, set it yourself: >

    vim.api.nvim_set_hl(0, "@function.macro", { link = "Statement" })
<
The same applies to overriding either group to taste: >

    vim.api.nvim_set_hl(0, "@function.builtin.ruby", { link = "Function" })
<
==============================================================================
FOLDING ~

                                                          *ruby_minitest_fold*
The `g:ruby_minitest_fold` option no longer exists.  The stock Ruby treesitter
`folds.scm` already folds `(do_block)`, which covers `describe` and `it`, so
enabling treesitter folding is all that is needed: >

    :set foldmethod=expr
    :set foldexpr=v:lua.vim.treesitter.foldexpr()
<
